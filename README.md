# 📷 Projeto Catálogo Diane Arbus - Galeria Digital Interativa & UI/UX Design

Este repositório contém a implementação Frontend de um catálogo digital interativo e imersivo dedicado à obra da icónica fotógrafa Diane Arbus. 

O principal objetivo do projeto foi transpor a experiência tátil de um catálogo artístico físico para o ambiente digital. Toda a interface foi estruturada com um design minimalista focado na visualização artística, tirando partido de uma arquitetura baseada em componentes reutilizáveis para gerir a galeria de fotografias, autorretratos e os respetivos contextos históricos.

O ciclo de desenvolvimento seguiu rigorosamente a metodologia Design-to-Code, sendo totalmente planeado no **Figma** e posteriormente codificado para garantir uma fidelidade visual absoluta (pixel-perfect) e total responsividade.



## 🛠️ Tecnologias e Destaques Técnicos


* **Framework & Linguagem:** React, TypeScript, Vite
* **Styling & UI:** Tailwind CSS, componentes estruturados com foco em acessibilidade (shadcn/ui)
* **Componentes Customizados:** Implementação de uma mecânica interativa de paginação (FlipBook / Page-Flip) para simular o manuseamento de um catálogo real.
* **Design & Prototipagem:** Figma



## 🚀 Como executar o projeto

Para inicializar o ambiente de desenvolvimento local com compilação rápida de assets (HMR via Vite), abre o terminal na pasta raiz do projeto e executa:

```bash
npm install
npm run dev
```
